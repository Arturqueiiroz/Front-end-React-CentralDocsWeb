# Front-end React CentralDocsWeb

Aplicação web desenvolvida em React para a plataforma CentralDocs, voltada para a gestão, navegação e organização centralizada de documentos. Desenvolvida no contexto acadêmico para prática de desenvolvimento web e integração de interfaces com APIs RESTful.

## Visão Geral

Este projeto foi desenvolvido como parte de atividades acadêmicas com o objetivo de criar uma interface web moderna, responsiva e dinâmica para a plataforma CentralDocs. O sistema permite interações em tempo real com documentos, oferecendo uma experiência fluida de usuário (UI/UX) integrada à API backend.

---

## Funcionalidades

* **Painel de gerenciamento:** visualização, consulta e organização de documentos e categorias;
* **Interface responsiva:** layout reativo adaptado para diferentes resoluções e dispositivos;
* **Integração com API:** consumo de rotas RESTful para sincronização de dados;
* **Arquitetura baseada em componentes:** modularização da interface para alta reutilização de código.

---

## Estrutura do Projeto

```text
Front-end-React-CentralDocsWeb/
├── public/                # Arquivos públicos e ícones estáticos
├── src/
│   ├── assets/            # Imagens, logotipos e estilos globais
│   ├── components/        # Componentes reutilizáveis da interface
│   ├── pages/             # Páginas da aplicação (Dashboard, Documentos, etc.)
│   ├── services/          # Configuração de chamadas HTTP (Axios/Fetch)
│   ├── routes/            # Definição e navegação de rotas web
│   ├── App.jsx            # Componente principal
│   └── main.jsx           # Ponto de entrada da aplicação
├── package.json           # Dependências e scripts do projeto
└── vite.config.js         # Configurações do bundler

```

## Tecnologias Utilizadas

* **React:** biblioteca principal para construção da interface de usuário;

## Como Executar

### Pré-requisitos

* [Node.js](https://nodejs.org/) instalado;
* Gerenciador de pacotes (`npm` ou `yarn`).

### Passos

1. Clone o repositório:

```bash
git clone [https://github.com/Arturqueiiroz/Front-end-React-CentralDocsWeb.git](https://github.com/Arturqueiiroz/Front-end-React-CentralDocsWeb.git)
cd Front-end-React-CentralDocsWeb

```

2. Restaure as dependências:

```bash
npm install

```

3. Execute o aplicativo em modo de desenvolvimento:

```bash
npm run dev

```
